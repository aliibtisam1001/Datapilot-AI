The pipeline

Every question follows the same five steps

No black box — each step is a real, inspectable stage between your question and the answer.

1

Ask

Type a question in plain English in the chat interface.

2

Generate SQL

The LangChain agent reads your schema and drafts a query.

3

Guardrail check

Only SELECT survives. Anything else is rejected before it runs.

4

Run + chart

The query executes and the result auto-picks a chart type.

5

Explain

The model summarizes the finding in two or three sentences.

Safety layer

What gets through, what gets blocked

The guardrail layer inspects every generated query before it ever touches your database.

Allowed ✓

  • ✓ SELECT ... FROM orders
  • ✓ Joins across products, customers, order_items
  • ✓ Aggregations, GROUP BY, date filters
  • ✓ Capped at 1,000 rows returned

Blocked ✕

  • ✕ INSERT / UPDATE / DELETE
  • ✕ DROP / ALTER TABLE
  • ✕ Statement chaining — ; --
  • ✕ Unbounded result sets

Try it yourself

Built for every kind of question

"What is the total revenue from delivered orders?"
SELECT ROUND(SUM(oi.price), 2) AS total_revenue
FROM order_items oi
JOIN orders o ON oi.order_id = o.order_id
WHERE o.order_status = 'delivered';
"How many unique customers are there in total?"
SELECT COUNT(DISTINCT customer_unique_id)
FROM customers;
"How many orders were placed each month in 2018?"
SELECT strftime('%Y-%m', order_purchase_timestamp) AS mo,
COUNT(order_id) FROM orders
WHERE strftime('%Y', order_purchase_timestamp) = '2018'
GROUP BY mo ORDER BY mo ASC;
"Which payment type generates the most total payment value?"
SELECT payment_type, SUM(payment_value)
FROM order_payments
GROUP BY payment_type
ORDER BY 2 DESC LIMIT 1;
"What are the top 5 product categories by revenue in English?"
SELECT t.product_category_name_english, SUM(oi.price)
FROM order_items oi
JOIN products p ON oi.product_id = p.product_id
JOIN product_category_name_translation t ON p.product_category_name = t.product_category_name
GROUP BY 1 ORDER BY 2 DESC LIMIT 5;
"What is the average delivery time in days?"
SELECT ROUND(AVG(julianday(order_delivered_customer_date) - julianday(order_purchase_timestamp)), 2)
FROM orders WHERE order_status = 'delivered';
